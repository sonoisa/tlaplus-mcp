# タスクリスト

## タスク完全完了の原則

**このファイルの全タスクが完了するまで作業を継続すること**

### 必須ルール
- **全てのタスクを`[x]`にすること**
- 「時間の都合により別タスクとして実施予定」は禁止
- 未完了タスク（`[ ]`）を残したまま作業を終了しない

### タスクスキップが許可される唯一のケース
以下の技術的理由に該当する場合のみスキップ可能:
- TLA+の表現力では対象の性質をモデル化できない
- 設計ドキュメント側の情報が不足しており、モデル化の前提が立てられない
- 前の検証項目の結果により、この項目の検証が無意味になった

スキップ時は必ず理由を明記:
```markdown
- [x] ~~タスク名~~（スキップ理由: 具体的な技術的理由）
```

### TLA+実行でエラーが発生した場合
- SANY構文エラー → コードを修正して `sany_parse` 再実行（最大3回）
- PlusCal翻訳エラー → コードを修正して `pluscal_translate` 再実行（最大3回）
- TLCタイムアウト → CONSTANTS縮小、state constraint追加して再実行
- TLC状態空間爆発 → symmetry追加、CONSTANTS縮小して再実行
- 不変条件違反/時相性質違反/デッドロック → **正当な検証結果**として記録（エラーではない）
- 3回失敗 → エラー内容を結果ファイルに記録し、タスクに注釈を付けて完了扱い
